# 繁盛記 限定プレートの絵：ChatGPT 用プロンプト

繁盛記の実績でだけ手に入る、限定ネームプレート3枚を ChatGPT（画像生成）で作るためのプロンプト。
形式は `docs/stage6-art-prompts.md` のネームプレートと同じ（1枚の画像に横長のプレートを縦に並べ、あとで切り分ける）。

## 使い方

1. 段階6のプレートを作ったときと同じ会話があれば、その続きで下の「生成プロンプト」を送る（絵柄がそろう）。
   新しい会話で作る場合は、先に `docs/stage6-art-prompts.md` の「共通の指示」を送ってから、生成プロンプトを送る。
2. 気に入らない絵は「〇段目だけ描き直して。ほかはそのまま」と頼む。
3. できた画像を PNG で保存し、`art-src/stage6/plates-run.png` に置く。

## 生成プロンプト　保存名：`plates-run.png`

```
同じ形式で、ネームプレートを3枚描いてください。1枚の画像（1024×1024）に、横長のプレートを上から縦に3枚並べます。各プレートは横長で縦横比はおよそ 8:1（幅およそ960、高さおよそ120）。プレートの間は広めの透明の余白。名前の文字が載る中央〜左寄りは、豪華でも文字が読めるように模様を控えめにして落ち着かせてください。文字・数字は入れないでください。

この3枚は、酒場を四日間で大繁盛させる特別な遊びの記念品です。ふつうのプレートより「商売繁盛」「お祝い」の気分が伝わるように。

1段目「繁盛のれん」☆4（四日間を走りきった記念）：深い赤の暖簾（のれん）の布でできた札。上の辺に金色の竿、布の下半分に3〜4本の切れ目（のれんの割れ目）。布には金糸の小さな丸い紋が等間隔に並ぶ。両端に金の房飾り。布のやわらかな陰影と、金のやわらかな光。明るい文字が読める濃さの赤。

2段目「千両箱」☆5（五回走りきった記念。伝説級）：黒漆塗りの千両箱をモチーフにした札。左右に太い金の帯金具と鋲、四隅に金の角金具。右端に、ふたの隙間からのぞく小判の山と、こぼれた小判が1〜2枚。金具と小判に虹色にゆらめく箔の光。中央は黒漆のつやだけにして、明るい文字が読めるように。

3段目「秘伝の書」☆4（かけ合わせを全部見つけた記念）：生成り色の和紙の帳面をモチーフにした札。左端は朱色の綴じ糸でかがった背表紙。紙にはごく薄い罫線。右端に朱色の四角い判子（文字ではなく、鍋と湯気の小さな絵柄）と、金の小さな栞ひも。紙の端にわずかな使い込んだ風合い。中央は明るい紙のままにして、濃い色の文字が読めるように。
```

## 組み込み（2026-11-11 済み）

- 元画像：`art-src/stage6/plates-run.png`（ChatGPT の出力は 1254×1254。背景は透明なので、大きさが違っても切り分けられる）。
- `scripts/stage6-art.mjs` の `PLATES` に `plates-run` を足し、`node scripts/stage6-art.mjs` で切り分けた（高さ 96px の WebP）。
  書き出し先：`public/collection/plates/p-hanjofuda.webp`・`p-senryobako.webp`・`p-hidencho.webp`。
- このスクリプトが作り直すのは `plates/`・`stickers/`・`sheets/` だけ（`README.md` と `fukubiki/` は消さない）。PNG の元画像もそのまま読める。
- 文字の色（`src/core/collectionItems.ts` の `text`）：繁盛のれん・千両箱は明るい文字、秘伝の書は濃い文字。絵の上で読めることを確認済み。
- 絵が読めないときだけ、コードで描いた仮の札を出す（`src/ui/nameplate.ts` の `drawRunPlate`）。
