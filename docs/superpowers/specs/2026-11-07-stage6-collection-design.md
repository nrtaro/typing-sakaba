# 段階6「名前の飾り」設計：コレクション・ふくびき・シール帳

ロードマップ #10。段階5の実績（`src/core/achievements.ts`）と、ひがわりのランキング表の上に作る。

## ねらい

遊ぶたびにコレクションが集まり、また遊びたくなる循環を作る。

- **実績限定コレクション**：実績を開くと手に入る。
- **ふくびき限定コレクション**：営業の売上をそのまま貯め、「ふくびき」を引いて集める。
- 見た目だけのもので、点数・営業の進み方・ランキングの順位には影響させない。

## 決めたこと（前提）

| 項目 | 決定 |
| --- | --- |
| 作り方 | すべて端末で完結する。サーバーには入手の記録を置かない |
| ずる | 許す。端末の記録を書き換えれば未入手の飾りも付けられるが、見た目だけなので守らない。サーバーは「決まった一覧にある ID か」だけ確かめる |
| ランキングに見せるもの | 二つ名とネームプレート。打鍵音・シールは自分だけ |
| 数 | 156 個。後から一覧に行を足すだけで増やせるようにする |
| シールの絵 | ユーザーが新しく用意する。届くまでは仮の絵で作る |
| 料金 | 無料。課金はしない |

## 1. お金とふくびき

- **貯金箱**：正常に閉店して結果が確定した通常営業・ひがわり営業の売上を、そのまま貯金箱に足す。数える営業は段階5の記録と同じ（練習・デモ・途中でやめた営業は数えない）。公開前の売上は残っていないので、全員 0 円から始める。
- **最初の1回は無料**。
- **ふくびき**：1回 5,000 円（ふつうに遊んで 1〜2 営業で1回。2026-11-09 に 8,000 円から変更）。タイトルの「ふくびき」から開く。1回ずつ引く（10連はなし）。
- **ふくびきは1種類**。ふくびき対象の飾りは、種類を問わずすべてこの1つから出る。
- **レア度は☆1〜5**。

  | ☆ | 1回で出る確率 | かぶったときのおまけ札 | 交換に要るおまけ札 | 見た目 |
  | --- | --- | --- | --- | --- |
  | ☆1 | 40% | 1 枚 | 5 枚 | ふつう |
  | ☆2 | 30% | 2 枚 | 10 枚 | ふつう |
  | ☆3 | 18% | 5 枚 | 25 枚 | キラキラ |
  | ☆4 | 11% | 15 枚 | 75 枚 | キラキラ（強め） |
  | ☆5 | 1% | 50 枚 | 200 枚 | ホログラム |

- **引き方**：先に☆を決め、その☆のふくびき対象すべての中から同じ確率で1つ選ぶ。種類ごとの出やすさは、その☆にある数で決まる。持っているものも出る（かぶる）。
  - 二つ名は「前の言葉」1つを1枠として数える。前の言葉が選ばれたら、同じ☆の後ろの言葉を1つ同じ確率で選び、2つ一緒に出す。かぶりは言葉ごとに判定する。
- **かぶり（天井）**：かぶった飾りは、☆に応じた枚数の「おまけ札」に変わる。おまけ札で、まだ持っていないふくびき対象を好きに選んで交換できる（二つ名は言葉1つずつ）。
- **実績限定の飾り**はふくびきに出ず、交換もできない。
- 値段・確率・枚数は一か所（定数）にまとめ、遊んでから調整できるようにする。
- ある☆のふくびき対象をすべて持っていても、その☆は出る（かぶりになっておまけ札が増える）。全部そろっても引ける。

## 2. コレクションの中身（156個）

| 種類 | 実績限定 | ふくびき（☆1/2/3/4/5） | 計 |
| --- | --- | --- | --- |
| 二つ名・前の言葉 | 6 | 34（12/10/6/4/2） | 40 |
| 二つ名・後ろの言葉 | 6 | 34（12/10/6/4/2） | 40 |
| ネームプレート | 4 | 20（6/5/4/3/2） | 24 |
| 打鍵音 | 2 | 14（4/4/3/2/1） | 16 |
| シール（4シリーズ×9枚） | 8 | 28（8/7/5/4/4） | 36 |
| **計** | **26** | **130** | **156** |

- 実績26件それぞれに、実績限定の飾りを1つずつ割り当てる（種類をまたいで混ぜる）。実績限定の飾りにも☆を付け、見た目の光り方に使う。
- 1回のふくびきで出る種類のおおよその割合（上の数のとき。二つ名は前の言葉の数で数える）：

  | ☆ | 二つ名 | プレート | 打鍵音 | シール |
  | --- | --- | --- | --- | --- |
  | ☆1 | 12 | 6 | 4 | 8 |
  | ☆5 | 2 | 2 | 1 | 4 |

  数を足すと割合も変わる。実装では、☆ごと・種類ごとの出やすさを確かめる表をテストで出す。

### 二つ名

- 「前の言葉」＋「つなぎ」＋「後ろの言葉」の組み合わせ。例：のんびり＋な＋看板娘、稲妻＋の＋釣り人。
- 前の言葉は様子を表す言葉、後ろの言葉は人を表す言葉にして、どう組んでも読めるようにする。
- **つなぎ**は最初から自由に選べる：な／の／（なし）／のような／みたいな／という。集めるものではない。後から足せる。
- 前・後ろのどちらかを持っていないうちは二つ名を付けられない（名前だけになる）。
- 言葉は店の設定に合わせて Claude が下書きし、ユーザーが直す。

### シール

- 4シリーズ×9枚。各シリーズに実績限定シール2枚と☆5を1枚含め、実績とふくびきの両方で埋まるようにする。
- シリーズの仮案：「店の料理」「調達の旅」「酒場のお客さん」「家族の毎日」。
- 台紙に9つの決まった枠があり、手に入れるとその枠に貼られる。9枚そろうと台紙の限定デザインが完成する。
- 絵はシール1枚につき透過 PNG 1枚（約64px四方）、台紙はシリーズごとに2枚（未完成の絵と完成した絵）。キラキラ・ホログラムの光り方はコードで重ねるので、絵に描かなくてよい。

### ネームプレート・打鍵音

- **ネームプレート**：名前の後ろの枠と色。コードで描く。
- **打鍵音**：キーを打ったときの音。既存の音（`src/ui/audio.ts`）と同じくコードで作る。

### 名前の下書き

- 156個の名前・☆・割り当ての下書きは、実装計画の最初の手順で一覧ファイルとして作り、ユーザーが直す。

## 3. 画面と操作

すべてキーボードで操作でき、これまでどおり打って選ぶ。

- **タイトル**：「ふくびき」ボタンを足す（6つになるので幅を少し詰める）。「きろく」はコレクションの入口にし、中を「実績」「シール帳」「飾り」の3つのタブで切り替える。
- **ふくびき**：福引きのガラガラが回って玉が出る。玉の色が☆（白・緑・青・金・虹）。続けて飾りのカードを「NEW」か「おまけ札 ＋n」で見せる（二つ名は2つ並べる）。メニューは「ひく」「こうかん」「もどる」。貯金箱とおまけ札の数を常に表示する。
- **シール帳**：←→でシリーズを切り替える。持っていないシールは影絵と入手先（「実績：○○」か「ふくびき」）を出す。そろうと台紙の絵が完成する。
- **飾り**：二つ名（前の言葉・つなぎ・後ろの言葉）・プレート・打鍵音を選んで付ける。二つ名とプレートは名前の見本で、打鍵音はその場で鳴らして確かめる。
- **結果画面**：段階5の実績のお知らせの欄に「本日の売上 ＋○○円 → 貯金箱」をまとめ、引ける額なら「ふくびきが引けます」を出す。位置は今のままで、結果のメニューや名前入力と重ねない。
- **ランキング**：名前の横に二つ名を小さく、プレートは行の背景色と枠で見せる。タイトル・結果画面の上位の表示にも出す。二つ名が長いときは縮めて収める。

## 4. 保存・ランキング表・拡張

### 飾りの一覧

- 156個を1つの一覧ファイル（`src/core/collection.ts` の予定）に並べる。1行に、永続ID・種類・☆・入手先（実績の永続ID か、ふくびき）・シリーズと枠・名前・絵（または色・音の設定）を書く。つなぎも同じファイルに一覧で持つ。
- 増やすときは行を足す。ID は使い回さず、並べ替えや改名をしても保存が崩れないようにする（段階5の実績と同じ）。

### 端末の保存

- 新しい保存枠（`lastorder2.collection.v1` の予定）に、貯金箱・おまけ札・ふくびきで手に入れた飾り・付けている飾り（前の言葉・つなぎ・後ろの言葉・プレート・打鍵音）・無料の1回を使ったか、を残す。
- 売上は段階5の記録と同じ処理の中で、同じ営業IDを使って足す。営業を二度足さない。
- **実績限定の飾りは保存しない**。段階5の `unlocked` から導く。公開した時点で、すでに開いている実績の飾りは手に入っている。
- 保存なし・壊れた値・書き込み失敗でも、営業と結果画面は使えるようにする。付けている飾りが一覧から消えていたら、付けていない扱いにする。

### ランキング表

- D1 の `scores` に列を足す移行ファイル（`migrations/0003_...sql`）を作る：`title_front`・`title_link`・`title_back`・`plate`（どれも NULL 可）。過去の記録は NULL で、飾りなしで表示する。
- 送信に、付けている二つ名の3つの ID とプレートの ID を足す。サーバーは一覧（サーバーとゲームで共有するもの）にあるかを確かめ、ない ID は捨てて飾りなしで受け付ける（二つ名は3つそろって正しいときだけ残す）。点数の送信は失敗させない。古い版のゲームからの送信もそのまま通る。
- 自己ベストを更新した送信のときに、その時点の飾りを保存する。上位の取得 API は二つ名とプレートの ID を返す。
- ID だけを送り、言葉の文字列は送らない（表示はゲーム側の一覧で引く）。

### 絵の読み込み

- シールと台紙の絵は、シール帳やふくびきを開いたときに読む。起動時の読み込みは重くしない。

## テスト

- ふくびきの☆の割合（多数回）、☆の中で同じ確率で選ばれること、二つ名が前と後ろの組で出て同じ☆になること。
- かぶり → おまけ札（言葉ごと）、交換（足りないとき・持っているもの・実績限定は交換できない）。
- 最初の1回の無料、貯金箱が足りないときは引けないこと。
- 同じ営業の売上を二度足さない、練習・途中でやめた営業は足さない。
- 実績限定の飾りがふくびきに出ず、実績を開くと持っている扱いになること。
- シリーズの完成判定。
- 旧セーブ（段階6の保存がない）・壊れた値の読み込み、一覧から消えた飾りを付けていた場合。
- 一覧の ID が重ならないこと、156個の内訳と☆の配分、実績26件にちょうど1つずつ割り当たっていること。
- サーバー：知らない ID を捨てること、二つ名の一部だけ正しい場合は捨てること、飾りなしの古い送信が通ること、上位の取得で飾りが返ること。

## 公開の手順の注意

- 本番の D1 に列を足す移行を、新しい版に切り替える前に流す。列を足すだけなので、古い版のサーバーにも影響しない。
- 移行・公開・main への反映は、ユーザーが明示的に依頼してから行う。

- サーバーでの入手の保証。
- 店の内装の飾り、常連客の図鑑、思い出の品（後から種類として足せる形にはしておく）。
