# LAST ORDER（仮題）設計メモ — 家族の酒場・3分タイピング営業

旧版（7日間の経営シミュレーション）から、企画者との相談で方針を全面的に変更した。
数値はすべて `src/core/shopConfig.ts` にまとめ、調整できるようにしている。

## 1. 確定した方針（企画者と合意済み）

- 一日（1プレイ）＝ **3分** のスコアアタック。朝・昼・夜で見た目もゲーム内容も変わる。店は成長しない。
- 家族3人で営む酒場：ごつい男前で明るい **マスター**、頼りになる明るい **おかみ（嫁）**、華奢で明るい **看板娘（娘）**。
- 操作は **キーボードで打つだけ**。入力欄は作らず、打った文字は対象の上の演出で示す。
  - 絞り込み中だけ、画面下に打った途中のローマ字を薄く出す。
  - **Backspace：1文字戻す／Space：打った文字を全部やり直す**。
  - タイトル・遊び方・結果画面の移動も打って選ぶ（はじめる／あそびかた／もどる／もういちど／たいとる）。
- 注文：客の頭上の料理名を打つと料理を出す（素材を消費）。
  - 打ち始めると、合う候補（注文・調達の言葉）が全部光り、打つほど絞り込まれる。
  - **同じ料理の注文が複数あるときは、待ち時間の残りが少ない客から出す**。
- 素材：魚・肉・野菜・きのこ・酒・香辛料。料理ごとに組み合わせが違う。
- 調達：入力欄と同じ扱いで言葉を打つと、担当が出かけてミニゲームになる。
  - つり＝おかみ（魚）、かり＝マスター（肉）、さいしゅ＝看板娘（野菜・きのこ）、しいれ＝マスター（酒・香辛料）。
  - **お金は使わない**。誰が行っても店への影響は同じ。
  - 調達中：残り二人が客の機嫌を取るので **待ち時間バーは止まる**。**3分の時計は進む**。新しい客は入り口に並び、戻ると一気に席に着く。
- 画面：家族が営業する姿、席ごとの客・注文・待ち時間バー、素材の残り数を常に表示。調達の言葉と取れる素材は同じ枠・同じ色で結ぶ。
- 将来：結果に応じてゲーム内通貨を得て、スコアに関係ない見た目のカスタマイズやコレクションに使う（今回は未実装）。
- 表示はウィンドウいっぱい。ドット絵は親しみやすくきれいに。効果音・BGMは電子音系で生成し、**打鍵音に音程を付ける**（打つたびに音階が上がり、ミスで最初に戻る）。

## 2. 採用した仮案（数値は調整可能）

| 項目 | 仮の値 |
| --- | --- |
| 時間帯 | 朝50秒・昼60秒・夜70秒（計180秒） |
| 客席 | 8席（2列×4） |
| 客の来る間隔 | 朝 約5秒・昼 約3.6秒・夜 約2.8秒（一日で約45人） |
| 待ち時間 | 朝昼30秒・夜26秒 |
| 開始時の素材 | 魚5・肉4・野菜5・きのこ3・酒5・香辛料3 |
| 調達 | ミニゲーム10秒＋出発・帰還の演出各0.9秒。成績で量が増え、失敗しても最低限（4前後）は持ち帰る |
| スコア | 料理の値段＋早く出したチップ（待ち時間の残りに比例）× コンボ倍率（10コンボごとに+0.5、最大2倍）。客が怒って帰ると −50 |
| ランク | S 12,000／A 9,000／B 6,000／C それ未満（仮） |

## 3. 調達ミニゲーム（それぞれ違う体験）

| 調達 | 担当 | 求められるもの | 遊び方 |
| --- | --- | --- | --- |
| つり | おかみ | 正確さ | 浮きが沈むたびに短い語句を打つ。ミスなく続けると大物（魚が多く取れる） |
| かり | マスター | 速さと狙い分け | 走る獲物の単語を打って仕留める。最初の文字で狙いが決まる。大物は肉が多い |
| さいしゅ | 看板娘 | 見極め | 温室に野菜・きのこ・毒きのこが現れる。食べられるものだけ打って摘む（1回で4つ）。毒きのこを打つとかごから2つこぼれる |
| しいれ | マスター | 速さと正確さ | 隊商の商人に値切りの言葉を打つ。打ち切るたびに酒か香辛料の箱が1つ増える。ミスなしなら1つおまけ |

## 5. 構成

- `src/core/` — 計算処理（表示に依存しない・テストあり）
  - `romaji.ts` / `kana.ts` — ローマ字判定（複数の綴りに対応）
  - `candidates.ts` — 複数の候補を同時に絞り込む入力処理（営業・メニュー・ミニゲーム共通）
  - `shopConfig.ts` — 料理・素材・調達・時間帯・スコアの数値
  - `shop.ts` — 一日の営業（客・席・在庫・調達・スコア）
  - `minigames/` — 4つの調達ミニゲーム
- `src/ui/` — 描画・音・画面遷移（`art/` はコードで描くドット絵）
- `tests/` — 計算処理のテスト
