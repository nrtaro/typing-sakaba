# LAST ORDER（仮題）設計メモ

このメモは「過去に確定した方針」と「今回の実装で採用した仮案」と「未決定事項」を分けて記録します。
数値はすべて `src/core/config.ts` にまとめてあり、調整できます。

## 1. 確定方針（企画者が過去に明示した内容）

- SF系・文明崩壊後の世界で、勇者や冒険者のための酒場を営む。主人公は酒場のマスター。
- 最初は小さな店で客も少ない。
- マスター自身が狩りや釣りに出かけて材料を調達する。調達はそれぞれ異なる体験のタイピングゲーム。
- 結果に応じて良い材料が手に入り、料理に使って酒場を発展させる。
- 簡易経営。料理を登録すると自動で営業する。
- 緻密なピクセルアート。メイン画面は横に広い2D世界の中に一軒の酒場がある構成。
- アクティビティを始めると専用画面に切り替わる。
- 一周20〜30分のスコアアタック。限られた期間でどれだけ酒場を大きくできるかを競う。
- タイピングの速さ・正確さが結果に明確に反映される。どのアクティビティを選ぶかの判断も重要。
- 独創性があり、飽きずに練習できる。ゲーム性を必要以上に複雑にしない。

## 2. 採用した仮案（すべて変更可能）

### 一周の構成
- **6日間 × 1日3回の昼行動**、夜に自動営業（指示書の初期案は7日でしたが、1回の調達が約1分かかるため、20〜30分に収まるよう6日にしました）。
- 時間を消費するのは「調達に出る」（行動1回）と「開店する」（その日を終える）だけです。料理・メニュー・設備の操作は時間を消費しません。これは画面に明示します。
- 毎朝「今日の噂」（魚料理が人気／肉料理が人気／大部隊が来る／静かな夜）が出て、調達先の判断材料になります。乱数はシード固定で、同じ条件での再挑戦ができます。

### タイピング
- 日本語の問題文＋ローマ字入力。shi/si、chi/ti、tsu/tu、fu/hu、ja/zya/jya、促音の重ね打ちやxtu/ltu、「ん」のn/nn/xnなど、一般的な複数の綴りを受け付けます。
- 誤入力では進みません。ミスはその場で赤く表示します。
- 速度は **打鍵/秒**（ローマ字キーの数）で表示し、かなの文字数とは混同しません。
- 開始前に説明と3秒のカウントダウン。Escで一時停止、ウィンドウからフォーカスが外れると自動で一時停止します。

### 釣り（落ち着いたリズム・安定調達）
- 少し長めの語句を1つ打ち切ると小魚が釣れます。待ち時間は1秒前後と短くしています。
- ミスなしで語句を打つと「水面の静けさ」がたまり、満タンになると**大魚**が掛かります（語句3つで釣り上げ）。希少な魚は乱数ではなく、正確な入力で呼び込みます。
- 魚の品質（★1〜3）はその魚を釣る間のミス数で決まります。
- 失敗のリスクはほとんどありません。

### 狩り（瞬間的な判断・高リターン）
- 獲物が右から左へ走ります。獲物ごとに短い単語が表示され、**最初の1文字を打った獲物に狙いが定まります**（どれを狙うかの判断）。
- 単語1つで命中1回。体力分の命中で仕留めます。逃げ切られると何も得られません。
- 砂ウサギ（体力2、小さな肉×1）と、ときどき出る鉄角ジカ（体力5、大きな肉×2）。シカは高価ですが、時間内に仕留めないと全部無駄になります。
- ミスをすると獲物が驚いて足が速くなります。肉の品質はその獲物に対するミス数で決まります。

### 食材・料理
- 食材は4種類（小魚・大魚・小獣肉・大獣肉）。それぞれ品質★1〜3ごとに所持数を持ちます。
- 料理は6種類。料理を作るときに食材を消費し、完成品は在庫になります。営業では在庫を消費します（食材が二重に減ることはありません）。
- 料理の品質は使った食材の平均品質で決まり、価格は★2で1.3倍、★3で1.7倍。高品質の料理は評判も上げます。
- 魚と肉を組み合わせる料理は単品より高く売れるので、片方だけを続けるより両方を集めるほうが有利な場面があります。
- 1日に作れる料理の数は厨房の能力で上限があります。料理の在庫は翌日に持ち越せます。

### 自動営業
- メニューに載せられる料理の種類数は看板・内装のレベルで決まります。
- 来客数 ＝ 基本客数 ×（評判・看板・メニューの種類・今日の噂）。
- 実際に食事できる客数 ＝ min（来客数, 席数×2回転, メニュー上の料理の数）。各客が1品ずつ注文します。
- 営業後に、販売数・売上・残った料理・評判の変化と、「なぜ伸びたか／何が足りなかったか」を短く表示します。

### 設備（3種類×3段階）
- 客席：受け入れられる客数が増える。
- 厨房：1日に作れる料理の数が増える。
- 看板・内装：来客が増え、メニューに載せられる料理の種類も増える。
- 価格と効果を明記し、「残り何日で元が取れそうか」の目安も表示します。

### スコア
- **総合スコア ＝ 最終所持金 ＋ 設備評価額（購入額の50%）＋ 評判×3**
- 売上の累計は所持金と重複するので加算しません。設備は購入額の半分で評価するため、最終日に何でも買えば得になるわけではありません。
- 売れ残った料理と食材は0点です。
- ランク（C/B/A/S）のしきい値は仮設定です。

### 保存
- 一周の途中経過・設定・自己ベスト・直近の結果をブラウザ（localStorage）に保存します。
- 調達の途中でページを閉じた場合、その調達は再開時に最初からやり直しになります（行動回数は開始時点で消費済み）。

## 5. バランス確認とプレイ時間（2026-10-22 時点）

`npm run sim` で、一定の速さ・ミス率で打つボットに一周させた平均スコア（8シード）:

| 技能（打鍵/秒・ミス率） | スコア | ランク（仮） |
| --- | --- | --- |
| 初心者（2.0・10%） | 約2,500 | C |
| 平均（3.5・6%） | 約4,500 | B |
| 上級（5.0・4%） | 約7,000 | A |
| 熟練（7.5・2%） | 約8,900 | S |

同じ平均的な技能での方針別:

| 方針 | スコア |
| --- | --- |
| 噂と不足に合わせて釣り・狩りを選ぶ | 約4,500 |
| 釣りと狩りを交互 | 約4,300 |
| 釣りだけ | 約2,300 |
| 狩りだけ | 約1,900 |
| 設備を買わない | 約3,300 |

- 片方の調達だけを続けると、組み合わせ料理が作れず大きく不利になります。
- 設備投資は約4割スコアを押し上げますが、評価額は購入額の半分なので終盤の購入は得になりません。

### プレイ時間

ブラウザ上で一周を自動操作した計測では、ゲーム内の経過時間（調達18回＋夜6回の演出）が約15分でした。
これに人が説明・結果を読む時間（調達1回あたり約8秒）と、料理・設備の判断（1日あたり約1分）を加えると **約23〜25分** の見込みです。
人が実際に通しで遊んだ時間はまだ計測していません。結果画面にプレイ時間を表示しているので、実プレイで確認してください。
