# 段階6 プレート・シールの絵：ChatGPT 用プロンプト

ネームプレート24枚・シール36枚・台紙8枚を ChatGPT（画像生成）で作るためのプロンプト。
絵柄をそろえるため、**1回の生成で複数枚をまとめて1枚の画像に描いてもらい、Claude が切り分けてゲームに入れる**。

## 使い方

1. ChatGPT の新しい会話を開き、最初に「共通の指示」を送る。
2. 続けて下の生成プロンプトを**1つずつ**送る（全部で 4 + 4 + 8 = 16 回）。同じ会話の中で続けると絵柄がそろいやすい。
3. 気に入らない絵は「〇段目〇列目だけ描き直して。ほかはそのまま」と頼む。
4. できた画像を PNG で保存し、ファイル名を下の「保存名」にして Claude に渡す。切り分け・縮小・ゲームへの組み込みは Claude が行う。

> 補足：今のプレートはゲームがコードで描いている。絵に置き換えるため、受け取ったあとにゲーム側の描き方を画像を使う形に直す。

## 共通の指示（最初に1回だけ送る）

```
これから、ブラウザのタイピングゲーム「タイピング酒場」の収集アイテムの絵をまとめて描いてもらいます。以降の依頼はすべて、この指示に従ってください。

【ゲームの世界】
ファンタジー世界の小さな家族経営の酒場。おやじ（料理担当、赤いバンダナと口ひげ）、女将（釣りと帳場）、看板娘（明るい赤毛の給仕）の3人で営む。お客は旅の剣士・騎士・魔法使い・吟遊詩人・ロボットなど。料理は焼き魚・きのこ汁・肉の串焼き・香草パン・えーる（エール）など。食材は釣り・狩り・競り・採取で集める。

【絵柄】
- 16ビット時代のRPGのような、ていねいなピクセルアート。輪郭ははっきり、色数はしぼる。
- 夜の酒場のランプの光のような、あたたかいアンバー・こげ茶・深い赤・金を基調にした色。差し色に緑・青を少し。
- 親しみやすく楽しい雰囲気。表情や形はかわいく、でも子どもっぽすぎず、洗練されたまとまりを出す。
- 文字・ロゴ・数字・署名・透かしは絵の中に入れない。
- 写真風・3D風・ベタ塗りのフラットなベクター風にはしない。

【レア度の見せ方（☆1〜5。アイテムごとに指定します）】
- ☆1：素朴でシンプル。1〜2色、飾りは最小限。
- ☆2：小さな模様や質感が1つ加わる。差し色が1つ。
- ☆3：モチーフが豊かになり、銅や真鍮の小さな金属の飾りと、控えめなきらめき。
- ☆4：銀や金の凝った縁取り、宝石の小さな粒、やわらかな光。手間のかかった工芸品のような格。
- ☆5：伝説級。虹色にゆらめくホログラム（箔）の質感、宝石、特別な形の縁。ひと目で「当たり」とわかる華やかさ。ただし下品にならず上品に。

【背景】
- 指定がないかぎり、背景は透明（透過PNG）。透明にできない場合は、真っ白ではなく単色のマゼンタ（#FF00FF）一色にしてください（あとで抜きます）。
- 複数の絵を並べるときは、絵どうしが重ならないよう十分な余白をあける。
```

## 受け取ったあと（Claude が行うこと）

- まとめて描いた画像を1枚ずつに切り分け、背景を透明にそろえ、シールは 64×64、台紙は 192×192 に縮める（細部がつぶれる場合は大きめの解像度で持つ）。
- プレートは横長の画像として切り出し、ゲームの描き方を「コードで描く」から「画像を敷く」に直す。名前の文字の色は、各プレートの明るさに合わせて決める。
- シールの光り方（☆3〜4のキラキラ、☆5の虹の帯）を絵の上に重ねるかどうかは、絵を見てから決める。
