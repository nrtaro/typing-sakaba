# 新モード：三日仕込み（仮称）

2026-10-24時点の企画整理。ゲームの実装はまだ変更していない。

## 合意済みの方向

- 既存の3分間スコアアタックとは別モードにする。
- 3日間を通じて効果を組み合わせ、自分好みの営業形態を構築する。
- ユーモアと、効果が連鎖する気持ちよさ、別の組み合わせで再挑戦する楽しさを重視する。
- ゲーム内通貨を使うコンテンツは後日追加する。本モードの導入条件にはしない。
- 新しい画像の生成・適用に大きな手間がかからない方針とする。

以下は実装前の提案。名称・選択回数・効果・倍率は未確定。

## 基本ループ案

タイトルで「いつもの営業／三日仕込み」を選び、難易度を選ぶ。既存のタイピングによる画面遷移を使う。

1. 開店前：3択から最初の「店の方針」を1つ選ぶ。
2. 1日目：3分営業。閉店時に売上と方針の貢献を確認する。
3. 仕込み：3択から1つ選ぶ操作を2回。方針を追加する。
4. 2日目：3分営業。追加した効果の組み合わせを試す。
5. 仕込み：再び2つ追加する。
6. 3日目：最大5つの方針で3分営業。3日合計の結果と珍称号を表示する。

計9分＋選択時間。選択画面では営業時計を止める。3日目の閉店後に効果を引かせず、完成した構成を十分使って終える。

## 営業形態の例

単なる価格アップに偏らず、何を注文されるか・何を調達するか・どう提供するかが変わる効果を用意する。系統を固定するクラス選択ではなく、混ぜられる方針にする。

| 方向 | ユーモアのある方針例 | プレイヤーの判断・連鎖 |
| --- | --- | --- |
| おかわり酒場 | 「揚げ物は別腹」唐揚げ客が1回だけおかわり | 肉を多めに用意し、連続提供を狙う |
| 一杯付きの店 | 「とりあえず、もう一杯」料理の後に酒の追加注文 | 酒の在庫と調達時期を考える。おかわり系とも組める |
| 大物専門店 | 「本日のおすすめ：さっきのヌシ」大物捕獲で次の魚料理数皿に限定ボーナス | 釣りの直後に魚料理をまとめて提供する |
| 背水の台所 | 「おやじの見栄」在庫が少ない料理ほど価格上昇 | 欠品との境目で粘り、調達のタイミングを選ぶ |
| 連続提供の店 | 「領収書はいらない」連続提供で追加チップ | 安定した注文と素材供給を作り、連鎖を維持する |
| 家族総出の店 | 「女将の号令」帰還直後の数件は配膳と演出が加速 | 調達と提供を交互に回す。入力なしの自動完成にはしない |

追加注文も素材・入力・時間を必要とする。初回注文より十分待つ客にし、混雑時は発動を保留または上限で抑える。効果が生む追加注文から同じ効果を再発動させず、無限注文を防ぐ。

## 選択と気持ちよさ

- 効果の選択は無料。売上は記録であり、この段階では財布や購入画面を作らない。
- 3択には現在の構成とつながる候補を少なくとも1つ含め、同時に別方向の候補も出す。相性を短い文で示す。
- 候補の一覧から毎回同じ正解を選ぶ構造にせず、出題順・効果の組み合わせを変える。ランダムな素材配分も調達の判断に生かす。
- 発動時は直前の注文の近くに方針名・追加額を短く表示。コンボの文字と衝突させず、音は連鎖の順番で上昇させる。
- 複数の効果が重なったときに一段強い演出を出す。通常の提供を毎回最大演出にしない。
- 閉店時は合計額だけでなく「方針で増えた売上」「追加注文数」「一番稼いだ連鎖」を表示し、選んだ意味を伝える。
- 成績を文字だけの珍称号にする。例：「唐揚げ永久機関」「酒は別腹」「在庫ゼロ秒前」。効果未実装の段階で称号条件を確定しない。

## 日をまたぐもの・リセットするもの（案）

- 持ち越す：選んだ方針、日別成績、合計売上、構成に関する実績。
- リセットする：客・注文・コンボ・一日限りの効果カウンター・素材。在庫は各日バランス済みの初期配分を基本とし、持ち越しによる序盤の大量調達一択を避ける。
- ラン終了後：方針はリセット。発見した組み合わせ・珍称号・自己ベストは記録する。恒久的な能力上昇は今回の必須要素にしない。
- 閉店・方針選択の区切りで保存し、9分を一度に遊べない人も再開できる。営業途中からの再開は初期実装では対象外とし、その日の開始状態から再挑戦する。

## 現行コードに合わせた実装の境界

- 現行 `Shop` は1日分の営業を担当している。別のラン管理が日数・方針・集計・各日の開始を管理する。
- 通常モードでは方針効果を付けず、同じシード・難易度なら従来と同じ結果になることを回帰検証する。
- `Game.finish()` は現在、全結果を通常の自己ベストへ保存する。新モードでは日別集計に分岐し、既存記録へ混入させない。
- 保存先はモード・難易度別。ラン保存には形式のバージョン・シード・日数・方針ID・日別成績・開始状態を含める。
- 効果は入力成功・提供・捕獲・帰還などの確定した出来事で1回だけ発火させる。描画フレーム数に依存させない。
- 基本価格・追加チップ・倍率の適用順を決め、発生源を記録する。追加注文・売上ボーナス・画面演出それぞれに上限を設ける。
- 新規画像は必須にしない。既存の料理アイコン、家族、注文枠、パーティクル、生成音、文字の伝票を利用する。

## 初期実装の規模と確認項目（案）

方針12種類程度、3系統以上、明確な組み合わせ6組程度から試す。最初は3日分を通して動く小さな試作を作り、追加量よりも連鎖の手応えを優先する。

確認するもの：通常モード不変／日またぎの効果維持と状態初期化／重複発火と無限連鎖なし／モード別保存と再開／入力メニューの先頭文字競合なし／追加注文が配膳を詰まらせない／初心者でも3日完走できる／異なる構成に実際に異なる操作上の利点がある。

## 後日追加する事項

ゲーム内通貨の獲得・所持・使い道は保留事項として管理する。「酒場の裏帳簿」などの案を候補に残すが、本モードの方針選択と通貨購入を同一仕様にしない。通貨を導入する際に、3日間の選択を狭めず、恒久強化でスコア比較を崩さない仕組みを別途検討する。
