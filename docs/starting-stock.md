# 初期素材のランダム配分

ブランチ：`codex/combo-procurement-balance`。

## 意図と仕様

毎回、食材の残り数と序盤の注文を見て、最初にどこへ調達に行くかを考えられるようにする。

- 合計は従来と同じ30個。全体が豊富・不足になる抽選にはしない。
- 最初に不足役の調達先を4種類から抽選。採取なら野菜かきのこ、仕入れなら朝から使う酒を少なめにする。
- 不足役は2〜3個、ほかは基準配分付近でばらつかせ、合計30個へ再配分。
- 不足役以外は、朝の料理を最低2皿作れる量を確保。全体でも朝の料理がどれも最低1皿作れ、複数の主材料が同時に1皿分だけにはならない。
- 香辛料は朝の料理に使わないため、これだけを不足役にして最初の調達を誘導することはしない。
- 表示は既存の素材数を利用。自動で正解の調達先を示すヒントは付けず、注文と在庫を比較して選べるようにする。
- ゲームのシード付き乱数を使い、同じシードでは同じ配分を再現できる。基準設定とほかの営業の在庫は変更しない。

| 素材 | 初期個数の上下限 |
|---|---|
| 魚 | 2〜8 |
| 肉 | 2〜8 |
| 野菜 | 2〜8 |
| きのこ | 2〜6 |
| 酒 | 2〜7 |
| 香辛料 | 2〜4 |

上下限の中から独立に引く方式ではなく、総量と最低提供数も同時に満たす配分。したがって、各素材の最大量が同時にそろうことはない。

## 検証

- 1,000シードで合計30個、整数、各素材の上下限、朝の全料理の最低1皿分、朝料理全体の12〜18皿分、複数の主材料が同時に不足役にならないことを確認。
- 200シードで100種類を超える配分があり、全素材の個数が変わり、同一シードで再現できることを確認。
- やさしい・30 WPM相当・ミス率4%の30シードで、全て10皿以上を提供し、怒って帰る客は1人以下。
- 上記ボットの最初の調達は、釣り3回・狩り8回・採取16回・仕入れ3回。どの調達にも分かれた。これは注文に応じて選ぶボットの結果で、人間が最適判断できる割合を保証するものではない。
- 全難易度の技能別営業シミュレーションと既存の配膳・素材消費テストも継続。
