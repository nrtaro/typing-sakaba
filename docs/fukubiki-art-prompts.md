# ふくびきの絵：ChatGPT 用プロンプト（段階D）

ふくびきの画面を作り直すための絵。屋台の背景・ガラガラ・看板娘・玉・結果のカードを ChatGPT（画像生成）で作る。
プレートやシールと同じく、**まとめて描いてもらった画像を Claude が切り分けてゲームに入れる**。

## 演出の流れ（この絵で作るもの）

1. 酒場の一角の福引きの屋台。看板娘がガラガラの取っ手を握って待っている。
2. 「ひく」で看板娘がガラガラを回す（ガラガラの4コマ・看板娘の2コマを交互に）。
3. 玉が転がり出る。玉の色がレア度（☆1 白・☆2 緑・☆3 青・☆4 金・☆5 虹）。
4. 玉が光って割れ、結果のカード（☆ごとの枠）が大きく出る。☆4は光の柱、☆5は虹の光が画面に広がる（光はゲームが描く）。

## 使い方

1. ChatGPT の新しい会話で、まず「共通の指示」を送る（プレート・シールのときと同じ会話の続きでもよい）。
2. 下の生成プロンプトを1つずつ送る（全部で5回）。
3. 気に入らない部分は「〇〇だけ描き直して。ほかはそのまま」と頼む。
4. できた画像を PNG で保存し、書いてある保存名にして Claude に渡す。

## 共通の指示（最初に1回だけ送る）

```
これから、ブラウザのタイピングゲーム「タイピング酒場」の「ふくびき（福引き）」の画面の絵を描いてもらいます。以降の依頼はすべて、この指示に従ってください。

【ゲームの世界】
ファンタジー世界の小さな家族経営の酒場。おやじ（赤いバンダナと口ひげ）、女将（茶色の髪をまとめた落ち着いた雰囲気）、看板娘（明るい金髪のツインテールに赤いリボン、ピンクのワンピースと白いエプロン、元気で愛らしい）の3人で営む。

【絵柄】
- 16ビット時代のRPGのような、ていねいなピクセルアート。輪郭ははっきり、色数はしぼる。
- 夜の酒場のランプの光のような、あたたかいアンバー・こげ茶・深い赤・金を基調にした色。
- 親しみやすく楽しい雰囲気。お祭りのようなわくわく感がありつつ、洗練されたまとまり。
- 文字・ロゴ・数字・署名・透かしは絵の中に入れない。
- 写真風・3D風・フラットなベクター風にはしない。

【背景】
- 指定がないかぎり、背景は透明（透過PNG）。透明にできない場合は、単色のマゼンタ（#FF00FF）一色にしてください。
- 複数の絵を並べるときは、絵どうしが重ならないよう十分な余白をあける。
```

## 1. 屋台の背景　保存名：`fukubiki-bg.png`

```
ふくびきの画面の背景を描いてください。横長 16:9（1536×864）。背景は透明にしない（これが画面全体の絵になります）。

夜の酒場の一角に出した、小さな福引きの屋台。紅白の幕と提灯、木のカウンター、上に吊るした小さな旗飾り。カウンターの後ろの壁には景品の棚（ジョッキやぬいぐるみ、包みなど。文字は入れない）。

構図の決まり：
- 画面の左寄り（左から30%あたり）のカウンターの上に、ガラガラを置く台だけを描く（ガラガラ本体と看板娘は別の絵で重ねるので描かない）。
- 画面の右半分は、結果のカードを大きく重ねるので、手前に物を置かず、少し暗めで落ち着いた背景にする。
- 画面の下 15% は、ゲームのボタンを置くので、暗い木のカウンターの前板にする。
```

## 2. ガラガラ（4コマ）　保存名：`fukubiki-drum.png`

```
福引きのガラガラ（八角形の木の抽選器）を4コマ描いてください。1つの画像（2048×512）に、横に4つ並べます。背景は透明。

- 赤と金で塗られた八角形の胴、木の台、右側に回す取っ手。胴の正面に金の飾り鋲。
- 4コマは、胴が少しずつ回転した絵（0度・22度・45度・67度くらい）。台と取っ手の付け根の位置は4コマとも同じ場所に描く（重ねて回転に見せます）。
- 取っ手も胴の回転に合わせて位置を変える。
- 4コマとも同じ大きさ・同じ位置。
```

## 3. 看板娘（2コマ）　保存名：`fukubiki-girl.png`

```
ガラガラを回す看板娘を2コマ描いてください。1つの画像（1024×512）に、横に2つ並べます。背景は透明。腰から上。

- 明るい金髪のツインテールに赤いリボン、ピンクのワンピースと白いエプロン。にこにこ楽しそう。
- 1コマ目：両手で取っ手を握って、腕を上にまわしたところ。
- 2コマ目：腕を下にまわしたところ（目を閉じて「えいっ」という表情）。
- 2コマとも同じ大きさ・同じ位置（交互に出して、回しているように見せます）。ガラガラは描かない（別の絵を重ねます）。
```

## 4. 玉（5色）　保存名：`fukubiki-balls.png`

```
福引きの玉を5つ描いてください。1つの画像（1280×256）に、横に5つ並べます。背景は透明。どれも同じ大きさの、つやのある丸い玉。

左から：
1. 白（☆1）：素朴な白い玉。
2. 緑（☆2）：つやのある緑の玉。
3. 青（☆3）：深い青の玉に、小さなきらめき。
4. 金（☆4）：金色に輝く玉、まわりに小さな光の粒。
5. 虹（☆5）：虹色にゆらめくホログラムの玉、宝石のような輝き。伝説級の当たり。
```

## 5. 結果のカードの枠（☆1〜5）　保存名：`fukubiki-cards.png`

```
福引きの景品を見せるカードの枠を5枚描いてください。1つの画像（2560×1024）に、横に5枚並べます。背景は透明。どれも縦長（縦横比 3:4 くらい）で、同じ大きさ。

カードの中央（全体の7割くらい）は、景品の絵や名前を重ねるので、無地に近い落ち着いた色にしてください。飾りは縁と四隅に寄せます。文字は入れない。

左から：
1. ☆1：素朴な木の札。細い縁。
2. ☆2：木の札に緑の布を張り、小さな金具。
3. ☆3：青い布に銅の縁取り、四隅に小さな飾り鋲と控えめなきらめき。
4. ☆4：深い紺に金の唐草の縁取り、四隅に宝石、やわらかな光。
5. ☆5：真珠色の地に、虹色にゆらめくホログラムの縁、宝石と光の粒。伝説級の華やかさ。
```

## 受け取ったあと（Claude が行うこと）

- 背景はそのまま、ほかはコマ・玉・カードごとに切り分けて `public/collection/fukubiki/` に入れる。
- ガラガラの4コマと看板娘の2コマを交互に出して回す動きを作り、玉が転がって割れ、カードが大きく出る流れにする。
- ☆4の光の柱と☆5の虹の光、カードの上のきらめきはゲームが描く。
