## 目安から外れているもの（次の段への持ち越し）

1. **上位5%の皿が ×13〜14 で、目安の ×15 にあと少し**。新しい方針5つ（第3段）で重ねる組み合わせが増えれば届く見込み。届かなければ第3段で、せまい条件の倍率をもう一段上げる。
2. **上限に届く皿が最大4%で、目安の3%をわずかに超える**条件がある（解放後・低いのれん）。第3段で、どの組み方かを見て決める。
3. **予告で選ぶと得をする**は、まだはっきりしない。低いのれんでは quote が 334 と urgent の 322 より多いが、初回と高いのれんでは少ない。倍率の差がもっと大きくなる第3段で、もう一度見る。
4. **勢いの店（82→60）と連鎖の店（85→73）が、変える前より弱い**。勢いの店は、大入り袋を「10皿ごと」にした影響と考えられる。第3段の測定で、方針ごとの効いた皿の割合を見て決める。
5. **高いのれんは 86→66**。のれんの目標は第5段で決め直す。
