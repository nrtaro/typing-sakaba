# 効果音の大きさをそろえる（段階6の手直し・段階B）

効果音はすべてコードで作っていて、音ごとに大きさが決め打ちされていた。聞こえる大きさに差があったので、測って係数（`src/ui/audio.ts` の `FX_GAIN`）でそろえた。

## 測り方

- ブラウザーの `OfflineAudioContext` で効果音を1つずつ鳴らし（音は出さない）、効果音の出口の音を書き出す。
- 耳の感じ方に近づけるため、低い音を弱め（100Hz の高域通過）、高い音を少し強める（1500Hz から +4dB）。
- 0.4 秒の区間ごとの音の強さ（二乗平均）を求め、その最大を dB で表す。

## BGM との釣り合い（BGM を音源に替えたとき）

BGM を「音楽の卵」の音源（9曲）に替えたところ、効果音と打鍵音が BGM に埋もれた。同じ測り方（0.4 秒ごとの強さ）で比べた。

| | 測った値（dB） | 係数 | 係数をかけたあと（dB） |
| --- | --- | --- | --- |
| BGM（9曲の中央値。どの曲も −13〜−15） | 約 −14.5 | 0.085（以前は 0.22） | 約 −36 |
| ふつうの効果音（そろえたあと） | 約 −36 | 2.0 | 約 −30 |
| 打鍵音 | 約 −41 | 2.2 | 約 −34 |

効果音が BGM より約 6dB 上、打鍵音が BGM より少し上になる。係数は `src/ui/audio.ts` の `BGM_GAIN`・`SFX_GAIN`・`KEY_GAIN`。設定画面の音量（0〜10、8 が基準）は、この上にかかる。
