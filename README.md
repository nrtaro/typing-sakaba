# タイピング酒場 ～おやじと女将と看板娘～

家族で営む酒場の、3分間タイピング営業ゲームです。
お客の頭上に出る料理名を打って料理を出し、素材が足りなくなったら「つり」「かり」「さいしゅ」「しいれ」と打って家族を調達に出します。朝・昼・夜の3分間でどれだけ売り上げられるかを競うスコアアタックです。

> 絵は生成画像のA案「琥珀の酒場」（配信用素材は `assets/amber-v3/`）を使っています。読み込めなかったときはコードで描いた簡易な絵で動きます。効果音・BGMはプログラムで生成した電子音です。

## 遊び方

- 難易度は「やさしい／ふつう／むずかしい」の3段階。自己ベストは難易度ごとに記録します。
- 操作はキーボードで打つだけ（IMEはオフ、半角英数）。入力欄はなく、打った文字は画面上の言葉に直接表れます。
- 打ち始めると、合う候補（注文・調達の言葉）がすべて光り、打つほど絞り込まれます。
- 同じ料理の注文が複数あれば、待ち時間の残りが少ないお客から先に出します。
- 調達はミニゲーム（約10秒）。調達中はお客の待ち時間が止まりますが、3分の時計は進みます。
  - つり（女将・魚）：浮きが沈んだら表示された言葉を素早く打ち、巻き上げる。釣り上げたら待たずに次の言葉を入力でき、速いほど多く釣れます。偶数匹目は大物。巻き上げ中のミスは糸のテンションに
  - かり（おやじ・肉）：走る獲物の単語を打って仕留める。最初の文字で狙いが決まる。小物は1発で肉3個、大物は3発で肉12個
  - さいしゅ（看板娘・野菜ときのこ）：食べられるものだけ打って摘む。毒きのこは打たない
  - しいれ（おやじ・酒と香辛料）：ライバルの商人より先に品物の名前を打ち切って落札する
- 続けて料理を出すとコンボ。やさしいは2ミス、ふつうは1ミスまで維持でき、料理を出すたびに猶予が回復します。むずかしいはノーミス。10コンボごとに売上の倍率が上がります。
- 主菜は魚・肉などを2個使用。注文の素材アイコンの「×2」などが必要量です。釣りは小物4個・大物11個、狩りは小物3個・大物12個、採取は1回4個、仕入れは落札2個＋ノーミス1個。
- Backspace：1文字戻す　Space：打った文字をやり直す　Esc：一時停止
- タイトル・結果画面のメニューも打って選びます（はじめる／あそびかた／おと／もういちど／たいとる）。Enter でも先頭の項目を選べます。
- ウィンドウの縦横比に合わせて画面を広げるので、画面の外に黒い帯が出にくくなっています。

ローマ字は `shi/si`、`chi/ti`、`tsu/tu`、`fu/hu`、`ja/zya/jya`、促音の重ね打ちや `xtu`、「ん」の `n/nn/xn` などの一般的な綴りを受け付けます。

## 動かし方

Node.js 20 以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5280 を開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm test` | 計算処理のテスト（入力判定・営業・調達・保存） |
| `npm run sim` | ボットに一日を通しで遊ばせ、速さ別のスコアを表示 |
| `npm run build` | 型チェックと本番用ビルド（`dist/`） |

## 構成

- `src/core/` — ゲームの計算処理（表示に依存しない）
  - `shopConfig.ts` — 料理・素材・調達・時間帯・スコアなど、**調整用の数値はすべてここ**
  - `candidates.ts` — 画面上の候補を同時に絞り込む入力処理
  - `shop.ts` — 一日の営業
  - `minigames.ts` — 4つの調達ミニゲーム
  - `romaji.ts` / `kana.ts` — ローマ字入力の判定
- `src/ui/` — 描画・音・画面の流れ（`sprites.ts` と `room.ts` はコードで描くドット絵。画像を読み込めなかったときに使う）
  - `amber/` — A案の画像素材の読み込み（`art.ts`）、manifest どおりの切り出しと再生（`manifest.ts`）、配置の数値（`layout.ts`）
- `assets/amber-v3/` — A案の配信用ロスレスWebPと修正済み `manifest.json`。調達背景は出発時に読み込む。
- `assets/amber-v2/` — 比較・再生成用のPNG原本。
- `tests/` — テストとバランス確認
- `docs/DESIGN.md` — 確定方針・仮案・未決定事項
