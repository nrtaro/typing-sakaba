# LAST ORDER（仮題）

家族で営む酒場の、3分間タイピング営業ゲームです。
お客の頭上に出る料理名を打って料理を出し、素材が足りなくなったら「つり」「かり」「さいしゅ」「しいれ」と打って家族を調達に出します。朝・昼・夜の3分間でどれだけ売り上げられるかを競うスコアアタックです。

> ドット絵・効果音・BGMはすべてプログラムで描いた・生成した**仮素材**です。

## 遊び方

- 操作はキーボードで打つだけ（IMEはオフ、半角英数）。入力欄はなく、打った文字は画面上の言葉に直接表れます。
- 打ち始めると、合う候補（注文・調達の言葉）がすべて光り、打つほど絞り込まれます。
- 同じ料理の注文が複数あれば、待ち時間の残りが少ないお客から先に出します。
- 調達はミニゲーム（約10秒）。調達中はお客の待ち時間が止まりますが、3分の時計は進みます。
  - つり（おかみ・魚）／かり（マスター・肉）／さいしゅ（看板娘・野菜ときのこ）／しいれ（マスター・酒と香辛料）
- ミスなく続けて出すとコンボ。10コンボごとに売上の倍率が上がります。
- Backspace：1文字戻す　Space：打った文字をやり直す　Esc：一時停止
- タイトル・結果画面のメニューも打って選びます（はじめる／あそびかた／おと／もういちど／たいとる）。

ローマ字は `shi/si`、`chi/ti`、`tsu/tu`、`fu/hu`、`ja/zya/jya`、促音の重ね打ちや `xtu`、「ん」の `n/nn/xn` などの一般的な綴りを受け付けます。

## 動かし方

Node.js 20 以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5280 を開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm test` | 計算処理のテスト（入力判定・営業・調達・保存） |
| `npm run sim` | ボットに一日を通しで遊ばせ、速さ別のスコアを表示 |
| `npm run build` | 型チェックと本番用ビルド（`dist/`） |

## 構成

- `src/core/` — ゲームの計算処理（表示に依存しない）
  - `shopConfig.ts` — 料理・素材・調達・時間帯・スコアなど、**調整用の数値はすべてここ**
  - `candidates.ts` — 画面上の候補を同時に絞り込む入力処理
  - `shop.ts` — 一日の営業
  - `minigames.ts` — 4つの調達ミニゲーム
  - `romaji.ts` / `kana.ts` — ローマ字入力の判定
- `src/ui/` — 描画・音・画面の流れ（`sprites.ts` と `room.ts` はコードで描くドット絵）
- `tests/` — テストとバランス確認
- `docs/DESIGN.md` — 確定方針・仮案・未決定事項
