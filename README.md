# LAST ORDER（仮題）

文明崩壊後の世界で、冒険者のための小さな酒場を営むタイピングゲームです。
釣りと狩りのタイピングで食材を集め、料理をメニューに載せて自動営業し、6日間でどれだけ店を大きくできるかを競います（一周 約20〜30分）。

> ピクセルアート・効果音・BGMはすべてプログラムで描いた**仮素材**です。最終的なアートではありません。

## 遊び方

1. **昼：調達に出る（1日3回）** — 釣りか狩りを選んでタイピング。速いほど多く、ミスが少ないほど品質（★）の高い食材が手に入ります。
   - **釣り**：少し長めの語句を落ち着いて打つ。安定して集まり、ミスなく打ち続けると大物が掛かる。
   - **狩り**：短い単語を素早く打つ。最初の1文字で狙う獲物を選ぶ。大物は高いが、逃げられると何も得られない。
2. **料理・メニュー** — 食材から料理を作り、メニューに載せる（時間は使わない）。魚と肉を組み合わせた料理は高く売れる。
3. **夜：開店** — 自動営業。売れる数は「来客」「席」「料理」のうち一番少ないものまで。
4. **設備の改善** — 客席・厨房・看板/内装。スコアでは購入額の半分が評価額として残る。

スコア ＝ 最終所持金 ＋ 設備評価額（購入額の50%）＋ 評判×3

入力は日本語の読みをローマ字で打ちます（IMEはオフ、半角英数）。`shi/si`、`chi/ti`、`tsu/tu`、`fu/hu`、`ja/zya/jya`、促音の重ね打ちや `xtu`、「ん」の `n/nn/xn` など一般的な綴りを受け付けます。

## 動かし方

Node.js 20 以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5280 を開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm test` | 計算処理のテスト（入力判定・経営・スコア・保存）とバランス確認 |
| `npm run sim` | バランス確認だけを実行（技能別・方針別のスコアを表示） |
| `npm run build` | 型チェックと本番用ビルド（`dist/`） |

## 構成

- `src/core/` — ゲームの計算処理（表示に依存しない）
  - `config.ts` — 食材・レシピ・設備・日数・報酬・スコア係数など**調整用の数値はすべてここ**
  - `romaji.ts` / `kana.ts` — ローマ字入力の判定
  - `fishing.ts` / `hunting.ts` — 各アクティビティの進行
  - `game.ts` — 日数・行動・料理・営業・設備・スコア
  - `save.ts` — ブラウザへの保存
- `src/ui/` — 画面と描画（`art/` はコードで描くピクセルアート）
- `tests/` — テストとバランス確認用のボット
- `docs/DESIGN.md` — 確定方針・採用した仮案・未決定事項の整理
