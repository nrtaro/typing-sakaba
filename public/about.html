利用規約

「タイピング酒場」（以下「本ゲーム」）は、ブラウザで遊べる無料のタイピングゲームです。本ゲームを遊んだ時点で、この規約に同意したものとします。

1. 提供について

  • 本ゲームは無料で、現状のまま提供します。内容の変更、一時的な停止、提供の終了を、予告なく行うことがあります。
  • 本ゲームを遊んだこと、または遊べなかったことで生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。

2. ランキングについて

  • 「ひがわり営業」の結果は、名前を付けて送ると、その日のランキングに名前と売上が公開されます。
  • 次のことをしないでください。
    • 自動で入力するプログラムや改造などを使って遊ぶこと、作った記録や書き換えた記録を送ること
    • 他人を傷つける名前、差別的な名前、他人や団体になりすました名前、宣伝や個人情報を含む名前を使うこと
    • サーバーに過度な負荷をかけること、その他、運営を妨げること
  • 運営者は、不正と判断した記録や、ふさわしくないと判断した名前を、予告なく削除することがあります。

3. 規約の変更

この規約は、必要に応じて変更することがあります。変更後の規約は、このページに載せた時点から効力を持ちます。

4. お問い合わせ

ご意見・不具合のお知らせ・記録の削除の依頼は、GitHub の Issues へお寄せください（GitHub のアカウントが必要です。書き込んだ内容は公開されます）。

プライバシーポリシー

本ゲームは、広告やアクセス解析を使っていません。扱う情報と、その使い道は次のとおりです。

1. お使いの端末（ブラウザ）の中だけに保存するもの

  • 音量や前回選んだ難易度などの設定、自己ベスト、ひがわり営業の記録（直近30日分）
  • ランキング用の端末ID（ランダムに作った値で、あなたを特定するものではありません）と、前回入力した名前

これらはブラウザの保存領域（localStorage）にあり、運営者には送られません。ブラウザのサイトデータを消すと消えます。

2. ランキングに送るときに扱うもの

情報名前、日付と難易度、成績（売上・出した料理・最大コンボ・怒って帰った客・正確さ・打鍵の速さ）、遊んだ記録（乱数の種・キーを押した時刻の記録・仕込みの振り分け）、端末ID、IPアドレスから作った値、送った時刻
公開するもの名前、売上、順位
使い道ランキングの表示、記録が正しいかの確認、送信回数の制限（短い時間に何度も送られるのを防ぐため）
IPアドレスIPアドレスそのものは保存しません。秘密の鍵を使って元に戻せない値に変えてから保存します。
保存期間送信回数の確認に使う履歴は、およそ10分で消えます。成績は、ランキングを残すために、運営者が削除するまで保存します。削除の依頼は、上の「お問い合わせ」からお寄せください。

3. 外部のサービス

  • Cloudflare：本ゲームは Cloudflare Workers で配信し、ランキングを Cloudflare D1 に保存しています。配信のため、Cloudflare がアクセスの情報を扱うことがあります。
  • Cloudflare Turnstile：ランキングに送るときに、自動の仕組みからの送信でないかを確かめるため、Cloudflare がお使いの端末やブラウザの情報を扱います。くわしくは Cloudflare のプライバシーポリシー をご覧ください。
  • X（旧Twitter）：結果画面で「Xにポスト」を選んだときだけ、X のポスト画面を開きます。本ゲームから X へ情報を送ることはありません。

4. 変更

このポリシーは、必要に応じて変更することがあります。変更したときは、このページでお知らせします。
