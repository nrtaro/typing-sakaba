# シールと台紙の絵

段階6のシール帳で使う絵。今は仮の絵（色の丸と枠）が入っている。本物の絵は**同じファイル名で上書き**する。

| 種類 | ファイル名 | 大きさ |
| --- | --- | --- |
| シール | `st-<永続ID>.png`（例：`st-ale.png`） | 透過 PNG・64×64 |
| 台紙（未完成） | `sheet-<シリーズID>.png`（例：`sheet-food.png`） | PNG・192×192 |
| 台紙（完成） | `sheet-<シリーズID>-done.png` | PNG・192×192 |

- 永続IDとシールの名前は `src/core/collectionItems.ts` にある。名前が絵の指示になっている。
- 台紙は 3×3 の枠に分かれ、左上から右下へ枠 0〜8。シールはその枠の上に貼られる。
- キラキラ（☆3〜4）とホログラム（☆5）の光り方はゲームが重ねるので、絵には描かない。
- 仮の絵を作り直す：`python scripts/placeholder-stickers.py --force`
