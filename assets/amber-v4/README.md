# 琥珀の酒場 配信用素材 v4

- 原本のv3ロスレスWebPを保持し、配信には軽量な高品質WebPを使用する。
- 背景quality=88、人物・小物quality=94、method=6。RGBは非可逆圧縮。透明度は全ピクセルで元画像と完全一致することを検証。
- 画像の幅・高さ、コマの切り出し、登録位置、アニメーションはv3と同じ。ゲーム内の配置や大きさを変えない。
- 配信対象のユニークな18画像で24,292,898 → 7,598,868 bytes（約68.7％減）。家族3人が共有するfamily-walk.webpは1ファイルとして集計。
- 初期画面は12画像・5,528,100 bytes。4つの調達背景に加えて、wife-fishingとwildlifeも出発時または調達ヘルプを開くときに取得する。
- 背景だけでなく必要な専用画像がすべて揃ってから調達を開始。読込待ちで営業時間を消費しない。失敗時のコード描画と次回の再試行を維持する。
- 再生成：リポジトリ直下で `python scripts/optimize-images.py`（PillowとNumPyが必要）。数分かかる。検証値はoptimization.jsonに保存する。
- 画質検証は黒・白に合成した画像のPSNRと透明度一致に加えて、通常表示サイズの背景・家族・客・獲物・小物の目視比較を実施した。PSNRは主観画質の保証ではない。
- 初回ロードの実測条件と結果はdocs/load-performance.mdを参照。
