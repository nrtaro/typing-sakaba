# 琥珀の酒場 配信用素材 v3

- v2のPNGは保持し、ゲームはこのフォルダーのロスレスWebPを使用。
- PNG約28.5MBから配信用画像約23.0MBへ圧縮。黒・白への合成比較で見えるピクセルが一致することを検証。
- 背景4枚は調達開始時に取得。初期画面では読み込まない。読み込み待ちで営業時間を消費しない。読込失敗時はコード描画へ戻す。
- props-actionsの家具・道具・人物の切り出しを主連結領域へ絞り、前行の断片を除去。
- wife-fishingは内蔵image_genで浮きと垂れた糸を除去したもの。竿先から水面の浮き一つまでをコードで描く。
- 原本・生成指示の参照は fishing-source.json。prepare.pyは原本から配信形式とmanifestを作る補助。
- ゲーム本体はカウンター・家具・客席・注文枠・入口の配置を調整し、配膳を待ってから食事時間が進む。
- 狩りは小物HP1／肉2、大物HP3／肉12。調達開始の肖像は現在の人物画像から切り出す。
- wildlifeはセル境界を越えた脚を含む主連結領域で切り出し、隣の脚の混入を除去。動く足ではなく胴体を横位置の基準にする。
- マスターは作業通路へ置き、天板奥端（基準座標y=113）から手前を背景で隠す。狩りの文字は上へ積み上げず、小物の頭上・大物の頭の横へ追従する。
- 家族3人と客7種の歩行を胴体基準へ修正。歩行コマは移動距離に同期し、歩速は客の入退店84、女将と娘の配膳112（基準座標/秒）に調整。席までの距離に応じて入店時間を変え、0.45秒間隔で案内する。
- 商人と狩りのマスターは、セル境界で欠けていた靴・銃口を含めて切り出す。狩りのマスターは(49,207)、身長48の配置で全身を地面に置く。

v2のプレビューは旧素材の比較用。ゲームの現行表示とは異なる。

## 歩行の描き直し

家族3種は `family-walk.webp`、客7種は `guests-walk-v4.webp`。接地・通過・反対足の接地・反対足の通過の4コマへ更新し、既存の歩速・コマ切替タイミングは維持。原画PNG、生成元は `walking-generation.json`、再構築用の差分は `walking-manifest.json` に保持。旧アトラスの歩行行は比較用で、営業画面では新アトラスを使用する。
