# A案 素材見直し版 v2

## 採用データ

- 背景6枚：朝昼共用の酒場、夜の酒場、貯水池、荒野、温室、隊商。
- 家族3人の待機・歩行・配膳。看板娘の採取は一回再生。
- 客7種類の歩行と4つの表情。表情は状態に応じて切り替える。
- 動物2種の走行、商人交渉、狩り、家具・道具、食材・料理。
- 炎と湯気はループ、水しぶき・きらめきは一回再生後に非表示。
- 新規の master-stir.png：鍋と道具を固定した調理4コマ。
- 新規の wife-fishing.png：釣竿と立ち姿を固定した待機4コマ。
- manifest.json：切り出し、足元登録、一定倍率、再生順、速度、ループの有無。

## 不採用・不要なデータ

- family-master の12〜15番：包丁から鍋へ飛ぶため、旧調理は不採用。
- family-wife の12〜15番：投げる・待つ・釣果が飛ぶため、旧釣りは不採用。
- 商人のコインを掲げるコマ、狩りで銃を大きく下げるコマは通常の再生列から除外。
- 客の「笑顔→中立→怒り→食事」の自動ループは廃止。ゲームの状態を表す静止ポーズとして扱う。
- 旧版ZIP、途中の生成記録・補助スクリプト・スクリーンショットは配布ZIPから除外。旧版は削除していない。
- UI文字・枠・在庫数・バー・音符・影は既存コードで描けるため追加画像は不要。家族の肖像は頭部を利用可能。
- 元シートの一部だけが不要な場合、画像原本は保持し、manifest の deprecatedFrames と使用シーケンスで区別している。組み込み側は不採用コマを参照しない。

## 動きの修正

- 足元を不透明部分から求めて位置を登録。同じ動作内は一定倍率で描画し、コマごとの拡大縮小を避ける。
- 客はセルに混入した隣行の断片を除外するため、主となる連結領域の矩形を使用。
- 待機はほぼ静止＋短い瞬き。歩行は6fps、調理・釣りは5fps、採取は4fps。補間は使わない。
- 配膳は差し出す→戻すの順。採取は最後のかごを持つ姿で保持。状態とイベントを無条件にループしない。
- プレビューの「動作をもう一度」で一回動作を再生でき、「笑顔」選択で客の表情を切り替えられる。

## 確認の範囲と残る制約

シートの全コマを解析し、プレビューで再生・切り替えを確認した。画像の作り直しは内蔵image_genを使用し、原画像のピクセルの加工は行っていない。切り出し範囲と表示位置・速度による調整も含む。滑らかな補間より、少ないコマの穏やかな動きを優先している。

AI原画には細部の形の変化が残る。特に歩行は厳密な関節アニメーションではない。実際の移動速度との同期、反転、頭部の肖像切り出し、最終表示サイズでの視認性はゲーム組み込み時に確認が必要。背景も既存の家具座標と厳密に一致しない。ゲーム本体の変更は今回は行っていない。

revisions.json に新規2画像のプロンプトを記録。既存素材の出所は ../amber-v1/prompts.json。配布ZIPはPNG17枚、プレビュー、manifest、修正プロンプト、この文書を含む。
